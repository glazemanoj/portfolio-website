# Manoj Kumar | Executive Portfolio Website

A modern, high-performance personal portfolio website built for **Manoj Kumar** (Senior Vice President - Technical & Operations at ModDwell) using **Next.js 14**, **Tailwind CSS**, and **Framer Motion**.

## 🌟 Features
* **Executive Summary & About:** Highlighting 30+ years of leadership in structural glazing, fenestration, and Generative AI project handovers.
* **Filterable Projects Showcase:** Highlighting landmark projects across Airports, Tech Parks, Commercial Towers, and Educational Campuses.
* **30-Year Experience Timeline:** Interactive career journey across ModDwell, Sobha Ltd., BOSCO UAE, Noble Glazing, MES, and Alufit.
* **Technical Skills & Credentials:** Power BI, 5-Axis CNC programming, AI automation, certifications, and academic background.
* **Contact Channel:** Integrated inquiry form and direct contact details.

## 🚀 Getting Started Locally

```bash
# Install dependencies
npm install

# Run dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website.
